# 资源清单

> 原则：**同一时间只读一本。** 收藏 ≠ 学会。

## 现在正在用的（同一时间不超过 2 个）

| 资源 | 类型 | 用途 | 进度 |
|---|---|---|---|
| cppreference.com | 文档 | C++ 查语法，不从头读 | 随时查 |
| 《Pro Git》中文版 | 书 | 只读前 3 章 | 进行中 |

## C++

| 资源 | 说明 | 什么时候用 |
|---|---|---|
| [cppreference](https://zh.cppreference.com/) | 最准的 C++ 参考 | 随时 |
| 《C++ Primer》第 5 版 | 系统教材，很厚 | 查漏补缺，不硬啃 |
| 《Effective C++》 | 进阶条款 | **大二再看**，现在看会挫败 |

## 交互与设计

| 资源 | 说明 | 什么时候用 |
|---|---|---|
| 《设计心理学》Don Norman | 交互设计的地基 | 大一下 |
| 《点石成金》Don't Make Me Think | 可用性入门，薄 | 大一下 |
| [Nielsen Norman Group 文章](https://www.nngroup.com/articles/) | 免费、短、权威 | 每周一篇，练英文 |
| 《设计方法与策略》 | 方法论工具箱 | 大二 |

## 游戏设计

| 资源 | 说明 | 什么时候用 |
|---|---|---|
| 《游戏设计艺术》Jesse Schell | 游戏设计最全面的教材 | 大一下～大二 |
| 《游戏设计梦工厂》Tracy Fullerton | 偏流程和实践 | 大二 |
| 《Rules of Play》 | 偏理论，学院派 | 大二以后 |

## 工具

| 工具 | 用途 | 上手成本 |
|---|---|---|
| **Ren'Py** | 视觉小说，最快出成品 | 低（会写文字就行） |
| **Figma** | 界面设计、可交互原型 | 低 |
| **Godot** | 通用游戏引擎，开源 | 中（暑假再碰） |
| VS Code | 写代码 | 低 |
| Git / GitHub | 版本管理 | 低（已会基本操作） |

## 值得分析的 5 个游戏（按分析难度排序）

| 游戏 | 分析什么 | 难度 |
|---|---|---|
| 《去月球》To the Moon | 叙事如何驱动情绪 | ★ |
| 《极乐迪斯科》 | 对话系统与技能检定 | ★★★ |
| 《蔚蓝》Celeste | 手感（手感是交互设计的极致案例） | ★★★ |
| 《女神异闻录 5》 | UI 风格、日历节奏、日常/战斗切换 | ★★★ |
| 《空洞骑士》 | 无文字引导、地图与探索心理 | ★★★★ |

> 每两周选一个，用 `analysis/TEMPLATE.md` 写一页。不需要写长，需要写准。
