## 命名约定（Figma 里也照这个来）

```
NN-项目名-页面
例：01-vn-主菜单
```

## 每次设计前先回答三个问题

1. **玩家此刻想做什么？**（不是"我想展示什么"）
2. **他一眼能看到最重要的信息吗？**
3. **误操作了怎么办？**（能不能撤销、有没有确认）

## 界面自检清单

- [ ] 主次信息有层级（不是所有东西一样大）
- [ ] 关键操作的可点击区域足够大
- [ ] 有明确的反馈（点了之后发生了什么）
- [ ] 空状态、加载状态、错误状态都考虑过
- [ ] 用灰度看一遍，还能分清主次吗

## 设计说明要写什么

每个界面配一段话：

> 这个界面要解决的问题是 ______，我用 ______ 的方式处理，因为 ______。备选方案是 ______，放弃的原因是 ______。

**没有这段话的设计稿，等于没有设计。**
