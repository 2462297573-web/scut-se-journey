## 目录约定

```
learning/cpp/
├─ data-structures/
│  ├─ 01-dynamic-array/
│  │  ├─ main.cpp        ← 能被编译运行
│  │  └─ NOTES.md        ← 我的理解 + 遇到的问题
│  └─ ...
└─ notes/
   ├─ 指针与引用.md
   └─ RAII与智能指针.md
```

**每个实现都必须有一个 `NOTES.md`**，写三件事：

1. 这个结构解决了什么问题
2. 我自己写的时候卡在哪
3. 现在我能怎么向别人解释它

## 编译运行（MinGW / g++）

```powershell
cd learning\cpp\data-structures\01-dynamic-array
g++ -std=c++17 -Wall -Wextra main.cpp -o test.exe
.\test.exe
```

> 加上 `-Wall -Wextra` 让编译器把所有警告喊出来 —— 警告里藏着 bug。
