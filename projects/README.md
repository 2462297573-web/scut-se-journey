# 项目档案

> 一个项目一个文件夹。**做完了才建文件夹，不要先建空目录**（空目录是自欺欺人）。

## 目录约定

```
projects/
├─ 01-vn-prototype/          ← 视觉小说原型
│  ├─ README.md              ← 用 TEMPLATE.md 写
│  └─ (代码或链接)
├─ 02-figma-uiset/           ← 界面设计
└─ 03-xxx/
```

## 什么才算"一个项目"

必须同时满足三条：

1. **能被别人使用/游玩**（不是只有你能跑）
2. **有 README**（说清目标、设计、技术、结果）
3. **有复盘**（哪里失败了、下次怎么改）

达不到三条的，叫"练习"，放 `learning/`，不放这里。

## 为什么复盘最重要

面试时最容易被问倒的问题不是"你会什么技术"，而是：

> "这个项目里最难的地方是什么？你怎么解决的？如果重做你会怎么改？"

没有复盘的仓库，答不出这三个问题。
