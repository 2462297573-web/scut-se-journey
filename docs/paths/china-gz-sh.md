# 路径 A：国内就业（广州 / 上海）

## 目标岗位（按适配度排序）

| 岗位 | 匹配度 | 说明 |
|---|---|---|
| **交互设计师 / UX Designer** | ★★★★★ | 主线目标。软工背景 + 作品集，比纯设计背景多一项"能落地" |
| **游戏策划（系统 / 关卡 / 叙事）** | ★★★★☆ | 不需要美术功底；叙事方向和你写同人的能力直接相关 |
| **游戏 UI 设计师** | ★★★☆☆ | 要一定视觉能力，需要额外补 |
| **技术美术（TA）** | ★★☆☆☆ | 需要 Shader + 美术，门槛高，作为远期备选 |
| **客户端 / 前端开发** | ★★★☆☆ | 保底选项，你的专业对口，但要接受"写代码为主" |

> **数值策划要慎选**：对数学和建模要求高，正好是你的痛点。

## 作品集要求（国内交互岗）

面试官实际会看的四件事：

1. **设计过程**：你怎么发现问题、怎么定义问题（不是只有最终效果图）
2. **决策理由**：为什么用这个方案，放弃了什么
3. **用户验证**：有没有找人试过，改了什么
4. **落地能力**：能不能自己做出可点击原型（你的技术背景在这里是加分项）

> 学生作品集最常见的死法：**全是漂亮界面，没有一个"为什么"**。

## 需要提前准备的软技能

- 能把设计讲成 5 分钟的故事（面试必考）
- 会用 Figma 做可交互原型（不是只会静态图）
- 能看懂英文设计文档（Nielsen Norman Group 等）

## 风险与备选

| 风险 | 应对 |
|---|---|
| 交互岗 HC 少、竞争设计院校学生 | 强调"技术 + 设计"复合；同时准备游戏策划岗 |
| 秋招时间紧（大四上） | 大三暑假实习必须拿到，转正是最稳的路径 |
| 想读研但不想考数学 | 国内交互方向研究生多在艺术院校（需美术基础），软工背景更顺的是计算机/HCI 方向 —— 需提前查目标院校要求 |

## 一句实话

国内路线的核心不是"技术多强"，而是**"你有没有在真实项目里被真实用户折磨过"**。实习的价值就在这里。
