# 路径 C：欧洲硕士

> 之前提过"想去欧洲生活"。这里把可行性摊开：**欧洲内部差异极大，不能当成一个整体。**

## 按"性价比"排序

| 国家 | 代表院校 | 学费（非欧盟） | 语言 | 特点 |
|---|---|---|---|---|
| **德国** | 柏林工大、魏玛包豪斯、慕尼黑工大、亚琛 | 公立基本免学费（巴符州约 1500 欧/学期） | 英语项目有，德语更广 | **最便宜**，但申请流程硬、偏工程 |
| **芬兰** | 阿尔托 Aalto（游戏设计与 HCI 很强） | 约 1.5 万欧/年 | 英语 | 游戏/设计方向对口度最高 |
| **瑞典** | KTH、于默奥设计学院（Umeå） | 约 1.2–1.6 万欧/年 | 英语 | 交互设计传统强 |
| **荷兰** | 代尔夫特、埃因霍温、阿姆斯特丹大学 | 约 1.5–2 万欧/年 | 英语 | 英语环境好，产业连接强 |
| **丹麦** | 哥本哈根 IT 大学、皇家艺术学院 | 约 1.2–1.6 万欧/年 | 英语 | 游戏研究强 |
| **意大利** | 米兰理工 | 较低（按收入分级） | 英语/意语 | 设计强，但偏工业设计 |

生活费：约 800–1200 欧/月（北欧更高）。

> 数字会变，**一律以目标院校官网的国际生学费页为准**，不要用中介或二手帖子里的数。

## 申请要什么

| 材料 | 说明 |
|---|---|
| 学士学位 + 成绩单 | 通常要求相关专业背景，跨专业要补课程说明 |
| **作品集** | 设计类项目**必需**，是评审核心；技术类可放宽 |
| 英语成绩 | 雅思 6.5（小分 6.0）起，部分院校 7.0 |
| 动机信 / 研究计划 | 要写清"为什么是这个项目、这个方向" |
| 推荐信 | 2 封，找带你做过项目的老师 |

## 时间线（2030-09 入学）

```
2029-03  确定 5–8 个目标项目，整理要求表
2029-06  作品集 v1 完成（复用国内路线的三件套）
2029-09  雅思出分
2029-12  第一批申请（荷兰、芬兰通常 1 月截止）
2030-02  第二批（德国部分项目）
2030-04  录取结果
2030-09  入学
```

## 和你现有条件的匹配度

| 你的情况 | 对欧洲申请的影响 |
|---|---|
| 软工背景 | 申请 HCI/媒体技术类友好；申请纯设计类要作品集补足 |
| 作品集三件套 | **通用**，和国内就业、日本申请完全复用 |
| 数学一般 | 影响不大（除图形学研究型项目） |
| 家里预算有限 | 优先德国公立；或工作 1–2 年攒钱再走 |
| 想留下工作 | 荷兰（英语工作环境）、德国（工程岗多）相对容易；北欧岗位少 |

## 风险

- **学费 + 生活费对家庭是硬压力**，且欧洲多数国家不允许留学生随意打工覆盖开支
- 设计类项目评审主观，作品集决定生死
- 毕业后留下工作的政策各国不同，需提前查（荷兰的 orientation year 相对友好）

## 建议

**把欧洲当成"如果国内不理想、且家里能支持"的第二选择，而不是主计划。** 它的准备成本和国内就业高度重叠（作品集 + 英语），所以现在不用为它额外做事——这正是它适合作为备选的原因。
