# 路径 B：日本

> 日本这条路有两种完全不同的走法，**成本差 3 倍**。先搞清楚自己是哪一种。

## B1 vs B2：两种进入方式

| | **B1 日语授课（一般入試）** | **B2 英语授课（SGU / 英文项目）** |
|---|---|---|
| 语言要求 | 日语 **N2 起，N1 更稳** + 校内考/面试 | TOEFL 80+ / IELTS 6.0–6.5 |
| 准备周期 | 日语从零到 N2 约 **600 小时**，到 N1 约 **900+ 小时** | 英语 3–6 个月 |
| 每周投入（按 2 年算） | 约 **6–8 小时/周**，会吃掉你全部自主学时 | 约 1–2 小时/周 |
| 可选学校 | 全部 | 部分（东大、东工大/科学大、庆应、早稻田、筑波等有英文项目） |
| 毕业后就职 | 直接可用 | 需在读期间补日语 |
| 适配你 | ❌ 与"每周 6 小时上限"直接冲突 | ✅ **推荐** |

**结论：以 B2（英语项目修士）为主，把日语放到"到了日本再学"。** 这样你的时间预算不用被撕开，而且修士两年在日本，语言环境比在国内自学强得多。

> 代价：B2 的可选研究室比 B1 少，且部分教授只收日语学生。所以要提前查募集要项。

## 钱

| 项目 | 国公立 | 私立 |
|---|---|---|
| 検定料（报名费） | 约 3 万日元 | 约 3.5 万日元 |
| 入学金 | 约 28.2 万日元 | 约 20–30 万日元 |
| 学费/年 | 约 53.58 万日元 | 约 80–150 万日元 |
| 生活费/月 | 东京 10 万+，地方 6–8 万 | 同 |

**减免与奖学金：** 国公立普遍有"半免/全免"申请（看成绩和经济状况），另有 JASSO 奖学金、MEXT（大使馆推荐/大学推荐）。**这是日本相对欧洲的最大优势——实际支出可能比想象低很多。**

粗略估算：国公立 + 半免 + 打工，年支出可压到 8–12 万人民币。

## 时间线（如果 2030-09 入学）

```
2027-10  决定是否保留日本路径
2027-11  开始英语（托福/雅思），每周 1–2 小时，不着急
2028     保持 GPA；开始看目标研究室在做什么
2029-03  确定 3–5 个目标研究室，读教授的论文摘要
2029-06  联系教授（套磁），准备研究计划书初稿
2029-08  考出 TOEFL/IELTS
2029-10  出愿（提交材料）
2029-12  面试/校内考
2030-02  合格发表
2030-09  入学（或 2030-04）
```

> 若走 B1 日语授课，则上面每一步都要提前一年，且 2027 年就得开始日语 —— 那时你才大二，会很赶。

## 就职（修士毕业后）

- 日本是**新卒一括採用**（应届统一招聘），毕业前一年开始就活，节奏固定
- 游戏公司：任天堂、索尼、Capcom、Square Enix、万代南梦宫、FromSoftware、Cygames、Konami、Sega 等
- **设计/策划岗对日语要求接近母语级**；工程师岗（程序）对外国人友好得多
- 所以：如果目标是"在日本做游戏设计"，B2 入学后两年必须把日语练到 N2–N1，否则只能走程序岗

## 风险清单

| 风险 | 应对 |
|---|---|
| 教授不收英文项目学生 | 提前查研究室主页的留学生实绩，准备 5 个备选 |
| 研究计划书写不出来 | 大二开始读论文摘要，积累"我想研究什么" |
| 家里无法承担 | 优先国公立 + 申请减免；或先工作两年再申 |
| 日语跟不上就职 | B2 入学后第 1 年就必须开始日语，不能拖 |

## 一句实话

日本不是"便宜的退路"，是**一条需要提前两年布局、但天花板不错的路**。它的真正门槛不是钱，是**你能不能持续两年做一件看不到即时回报的事**。
