# 三条路径：对比与决策

> 目标不是现在就选，而是**把每条路的门槛看清楚**，这样才知道哪些准备是共通的、哪些是白费的。

## 一句话结论

| 路径 | 一句话 | 什么时候必须决定 |
|---|---|---|
| **A 国内就业（广州/上海）** | 最快变现、对数学要求最低、本地优势最大 | 2028 年暑假前（要开始找实习） |
| **B 日本修士** | 需要一门新语言，但学费可控、游戏产业成熟 | **2027 年 10 月前**（决定要不要开始学日语） |
| **C 欧洲硕士** | 作品集导向、英语即可、学费跨度大 | 2029 年初（要考雅思） |

## 对比表

| 维度 | A 国内就业 | B 日本修士 | C 欧洲硕士 |
|---|---|---|---|
| 需要的核心材料 | 作品集 + 实习经历 | 研究计划书 + 语言 + GPA + 出身校 | 作品集 + 雅思 + GPA + 课程匹配 |
| 语言成本 | 0（中文） | **高**：日语 N2→N1，约 1.5–2 年 | 中：雅思 6.5 |
| 时间成本 | 最短（2030 直接工作） | 2 年修士（2030–2032） | 1–2 年硕士 |
| 金钱成本 | 负（有收入） | 约 10–15 万人民币/年，有减免 | 约 10–25 万人民币/年 |
| 数学要求 | 低 | 低～中（看研究室） | 低～中 |
| 对"想创作"的友好度 | 中（工作强度大） | 高（修士時間相对自由） | 高 |
| 不确定性 | 低 | 中（考试制，需联系教授） | 中（作品集评审主观） |

## 决策树（按顺序问自己）

```
1. 家里能拿出 15 万/年 支持我读研吗？
   ├─ 不能 → 优先 A（国内就业），B/C 作为工作几年后的选项
   └─ 能 ↓
2. 我愿意在未来两年，每周额外投入 3–5 小时学一门新语言吗？
   ├─ 不愿意 → C（欧洲，只要英语）
   └─ 愿意 ↓
3. 我更想去日本生活，还是更想要"英语环境的国际经历"？
   ├─ 日本 → B
   └─ 欧洲 → C
```

> 注意第 2 条：**学日语会和你的"每周 6 小时上限"直接冲突。** 如果决定走 B，就要从其他项里砍掉等量时间（推荐砍掉"图形学"和"额外算法"）。

## 三条路的共用资产（无论选哪条都不浪费）

1. **作品集三件套**（体验分析 / 交互设计项目 / 可玩原型）
2. **C++ 与计算机基础**（国内就业的硬门槛、日本修士的考试内容、欧洲的课程匹配）
3. **GPA**（保研、日本、欧洲全都要）
4. **英语阅读能力**（三条路都是刚需）
5. **Figma 和 Ren'Py/Godot 的实操能力**

**会浪费的投入：** 过早深入图形学（除非确定走技术路线）、刷大量算法题（除非考研/竞赛）、考一堆证书。
