# 每周复盘怎么做（15 分钟）

> 目的不是"记录我有多努力"，而是**发现偏差**。
> 时间：每周日晚上，固定 15 分钟。写不完就写三行，别拖成负担。

## 为什么要有这一步

没有复盘的学习，会出现三种典型故障：

1. **假性进度**：感觉学了很多，但写不出一行代码
2. **方向漂移**：被刷到的视频带跑，两周后忘了原本在干什么
3. **情绪累积**：卡住的地方没人知道，越积越焦虑

复盘就是给这三件事装一个报警器。

## 四问模板（照抄进 `journal/YYYY-MM.md`）

```markdown
### 第 N 周（MM/DD – MM/DD）

**1. 这周实际做了什么？**（只写完成的事，不写计划）
-

**2. 卡在哪？**（写具体的技术点或情绪点）
-

**3. 下周最重要的一件事是什么？**（只写一件）
-

**4. 身体状态**（睡眠/情绪/有没有运动，一句话）
-
```

## 判断标准

| 情况 | 说明 | 动作 |
|---|---|---|
| 四周里有两周"这周实际做了什么"是空的 | 计划太满或目标太虚 | 下周只留一件任务 |
| 连续三周卡在同一个点 | 不是能力问题，是方法问题 | 换资料 / 找人问 / 拆小 |
| 每周学时长但零 commit | 在"看"不在"做" | 强制改成"先写一版再查" |
| 出现躯体不适、持续失眠 | **优先级高于一切** | 停学、就医、减负 |

## 每月末额外做一次（30 分钟）

在 `journal` 里那篇月度文件的末尾加：

```markdown
## 本月总结

- 交付物：<链接到 projects/ learning/ analysis/ 里的东西>
- 新增技能：
- 放弃/暂缓的事（以及为什么）：
- 下月唯一重点：
```

## 每学期末额外做一次（1 小时）

1. 打开 `docs/plan/roadmap-2026-2030.md`，看分叉时间表
2. 在文末「校准记录」加一行：改了什么、为什么
3. 只改一处，不要全盘重写（全盘重写=计划失效的信号）

## 不要做的事

- ❌ 不要在复盘里写"我这周太废了" —— 复盘是找偏差，不是自我审判
- ❌ 不要用"学习时长"当唯一指标
- ❌ 不要为了好看而补记（宁可空着）
